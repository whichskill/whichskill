# Installed skill catalogue — NOT GENERATED

This file is a placeholder. It ships empty on purpose.

The catalogue lists the skills installed on **your** machine, and there is no way
to know those in advance. Shipping the author's catalogue would make the router
name commands you do not have — confident, and useless.

Generate it once, now:

```bash
bash scripts/build-catalogue.sh
```

Run it again whenever you install or remove a pack.

Until then there is nothing to route over, and the hard rule stands: never invoke
a name that does not appear in this file.
